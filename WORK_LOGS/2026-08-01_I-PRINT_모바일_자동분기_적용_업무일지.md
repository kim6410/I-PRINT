# I-PRINT 모바일 자동 분기 적용 업무일지

작업 일시: 2026-08-01

## 작업 목적

사용자가 기본 주소 `/`에 접속했을 때 휴대전화는 기존 모바일 전용 화면 `/mobile`로 자동 이동하고, PC는 기존 대시보드를 그대로 표시하도록 FastAPI 라우트를 보강했습니다.

## 보호 원칙

- 기존 `mobile.html` 수정 없음
- 기존 PC `index.html` 수정 없음
- 모바일 반응형 화면 신규 제작 없음
- FastAPI `/` 라우트만 최소 수정
- `/mobile` 직접 접속 유지

## 수정 파일

- `/home/bourne/I-print/app.py`

## 구현 내용

### FastAPI import

- `Request` 추가
- `RedirectResponse` 추가

### `/` 라우트 동작

1. 쿼리 문자열 `view=pc`가 있으면 User-Agent와 관계없이 PC 화면 반환
2. User-Agent를 소문자로 변환
3. 아래 키워드 중 하나가 포함되면 `/mobile`로 302 이동
   - android
   - iphone
   - ipad
   - ipod
   - mobile
4. 그 외 접속은 기존 PC 화면 반환

## 검증 결과

- Python 문법 검사: PASS
- Git diff 검사: PASS
- 서비스 재시작 후 상태: active
- Windows User-Agent로 `/` 접속: HTTP 200, PC 화면
- Android Mobile User-Agent로 `/` 접속: HTTP 302, Location `/mobile`
- iPhone User-Agent로 `/?view=pc` 접속: HTTP 200, PC 화면
- PC User-Agent로 `/mobile` 직접 접속: HTTP 200, 모바일 화면

## 최종 접속 방식

- 휴대전화 기본 접속: `http://192.168.0.32:8897/` → `/mobile` 자동 이동
- PC 기본 접속: `http://192.168.0.32:8897/` → PC 화면
- PC에서 모바일 화면 확인: `http://192.168.0.32:8897/mobile`
- 휴대전화에서 PC 화면 강제 보기: `http://192.168.0.32:8897/?view=pc`
