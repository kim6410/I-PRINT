# I-PRINT 테마 보기 전환 오류 수정 업무일지

작성일: 2026-08-01

## 작업 배경

테마 보기 버튼을 추가했으나 실제 브라우저 화면에서는 리스트 보기 버튼이 계속 활성화되고 리스트형 카드가 유지되는 현상이 확인되었습니다.

## 원인

보기 전환 코드가 HTML 요소의 `id`를 브라우저 전역 변수처럼 사용하는 방식에 의존하고 있었습니다.

브라우저 환경과 캐시 상태에 따라 버튼 및 장치 목록 요소 참조가 안정적으로 보장되지 않아 테마 보기 상태가 정상 반영되지 않을 가능성이 있었습니다.

또한 장치 목록에는 기존 `list-view` 클래스만 토글하고 있어 세 가지 보기 상태가 명시적으로 구분되지 않았습니다.

## 수정 내용

- 저장된 보기 상태를 `list`, `card`, `theme` 세 값으로 검증
- 버튼과 장치 목록을 `document.getElementById()`로 직접 조회
- 보기 변경 때 기존 `list-view`, `card-view`, `theme-view` 클래스를 전부 제거
- 현재 보기 방식에 맞는 클래스 하나만 추가
- 장치 목록의 `data-view-mode` 값에 현재 보기 상태 기록
- 렌더러를 리스트·카드·테마 방식으로 명확하게 분리
- 테마 보기에서는 카드형 HTML과 `theme-card` 입체 스타일을 사용
- 사용자 선택은 기존 `localStorage`에 계속 저장

## 테마 보기 디자인

- 개별 컴퓨터 카드에 강한 외부 그림자
- 카드 상단 반사광과 하단 음영
- 내부 상태 박스와 계기판의 작은 그림자
- 마우스 오버 시 3px 상승
- 온라인·출력·대기·오류 상태별 테두리와 광원 표시

## 유지 사항

- 리스트 보기 UI 유지
- 일반 카드 보기 UI 유지
- 검색 기능 유지

- 대기열 초기화 기능 유지
- 사용자 보기 설정 저장 유지

## 검증

- 세 가지 보기 값 검증 코드 확인
- 테마 버튼 직접 요소 조회 확인
- 리스트 클래스 강제 제거 로직 확인
- 테마 전용 렌더러 확인
- 대시보드 HTTP 200
- 상태 API 정상
- UTF-8 및 HTML 스크립트 구조 정상
