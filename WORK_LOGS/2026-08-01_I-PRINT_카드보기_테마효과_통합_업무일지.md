# I-PRINT 카드 보기 테마 효과 통합 업무일지

작업일: 2026-08-01

## 작업 목적

기존의 리스트 보기와 카드 보기는 모두 유지한다.

별도로 추가했던 테마 보기 버튼은 제거하고, 테마 보기에서 사용하던 강한 입체 카드 효과를 카드 보기에 그대로 통합한다.

## 완료 내용

- 리스트 보기 유지
- 카드 보기 유지
- 테마 보기 버튼 제거
- 카드 보기에서 테마 카드 CSS 사용
- 온라인·출력 중·대기·오류 상태별 테두리 및 음영 유지
- 기존 브라우저에 저장된 `theme` 보기 값은 `card`로 자동 변환
- 보기 전환 로직을 `list`와 `card` 두 가지로 단순화
- 실시간 상태 갱신, 검색, 대기열 초기화 기능 유지

## 최종 보기 구조

1. 리스트 보기
   - 2열 컴팩트 프린터 중심 화면

2. 카드 보기
   - 3열 상세 카드 화면
   - 기존 테마 보기의 강한 입체감과 상태별 광원 효과 적용

## 보호한 기능

- 5800X 실데이터
- Mac mini 실데이터
- 5초 상태 갱신
- 검색
- SQLite 프린터 작업 이력
- 대기열 초기화
- 모바일 화면
- 히어로 이미지 전환 효과

## 검증 기준

- 리스트 보기 버튼 존재
- 카드 보기 버튼 존재
- 테마 보기 버튼 없음
- 카드 HTML에 `theme-card` 클래스 적용
- 렌더링 분기는 `listCard`와 `card` 두 개만 사용
- 저장된 보기 값은 `list` 또는 `card`만 사용
- HTTP 200
- Git 미추적 파일 0개
