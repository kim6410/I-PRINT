# I-PRINT 30개 지점 복합기 통합관제·QR 모바일 안내 플랫폼 사업계획서

작성일: 2026-08-01

프로젝트명: I-PRINT

사업 개념: 대학교·기관·기업의 다수 지점에 설치된 복합기와 연결 PC를 하나의 웹 대시보드에서 실시간으로 관제하고, 장애·소모품·출력량 데이터를 장기간 축적하며, 일반 사용자는 복합기에 부착된 QR코드를 통해 모바일 안내·장애 신고·전화·카카오톡 상담까지 이용할 수 있는 통합 운영 플랫폼

---

## 1. 사업계획서 작성 목적

현재 I-PRINT는 원격 PC와 프린터 상태를 웹 화면에서 확인하고, 프린터 대기열과 Windows Print Spooler를 관리할 수 있는 기본 구조를 갖추고 있다.

이번 사업계획서는 약 30개 지점에 설치된 기업용 HP LaserJet·네트워크 복합기와 전용 PC를 Tailscale 기반으로 연결하여 다음 목표를 달성하기 위한 전체 사업 구상을 정리한다.

1. 전체 지점의 PC·프린터·복합기 상태를 실시간으로 한눈에 확인한다.
2. 토너·용지·용지 걸림·오프라인·대기열 정체 등 주요 장애를 자동 감지한다.
3. 장애 발생과 복구 상황을 텔레그램으로 즉시 알린다.
4. 복합기에서 제공하는 상태·소모품·사용량 데이터를 DB에 장기간 축적한다.
5. 축적 데이터를 이용해 소모품 교체 시점과 장애 가능성을 예측한다.
6. 일반 사용자는 복합기에 부착된 QR코드로 모바일 안내 페이지를 열어 사용법·상태·문의처를 확인한다.
7. 관리자는 현장 출동을 최소화하고 30개 지점을 중앙에서 운영한다.

## 3. 현재 운영상의 문제점

### 3.1 상태 확인이 로컬 PC에 묶여 있음

현재 프린터 상태는 현장 PC 앞에 가거나 원격제어 프로그램으로 개별 접속해야 확인할 수 있다.

지점이 30개이면 관리자는 같은 확인 작업을 30번 반복해야 한다.

### 3.2 장애를 사용자가 먼저 발견함

용지 부족, 토너 부족, 프린터 오프라인, 용지 걸림, 대기열 정체가 발생해도 중앙 관리자는 바로 알기 어렵다.

결국 사용자가 전화하거나 카카오톡으로 문의한 뒤에야 장애를 알게 되는 경우가 많다.

### 3.3 과거 데이터가 남지 않음

프린터가 얼마나 자주 고장 나는지, 토너가 얼마나 빨리 소모되는지, 어느 지점의 출력량이 많은지 체계적인 데이터가 없다.

따라서 소모품 구매와 유지보수가 경험과 감각에 의존한다.

### 3.4 현장 안내가 부족함

일반 사용자는 복합기 사용법, 스캔 방법, 양면 출력, 이용 요금, 담당자 연락처를 한 번에 확인하기 어렵다.

문제가 생기면 어디로 연락해야 하는지 몰라 주변 직원에게 문의하거나 장비 사용을 포기한다.

### 3.5 관리 인력이 반복 업무에 소모됨

프린터 대기열 삭제, Spooler 재시작, 프로그램 업데이트, 로그 확인 등 원격으로 가능한 작업도 현장 담당자에게 요청하는 경우가 많다.

## 4. 해결 방안

I-PRINT는 각 지점의 전용 PC를 복합기 상태 수집기이자 원격 관리 중계기로 사용한다.

각 PC에 Tailscale과 I-PRINT 에이전트를 설치하고, 필요 시 관리자 SSH를 활성화한다.

에이전트는 Windows 프린터 상태와 복합기의 SNMP·내장 웹서버 정보를 수집해 Dell 서버로 전송한다.

Dell 서버는 최신 상태와 변경 이벤트를 DB에 저장하고, 관리자 대시보드와 모바일 화면에 표시한다.

장애 조건이 충족되면 텔레그램으로 알림을 전송한다.

일반 사용자는 복합기에 부착된 QR코드를 스캔해 해당 장비 전용 모바일 페이지에 접속한다.

### 9.4 장비별 고유 주소


```text

```

예시 2:

```text

```

## 10. 데이터베이스 설계 방향

30개 지점 규모에서는 SQLite로 시작해도 충분하다.

단, 매초 모든 원시값을 계속 저장하는 방식은 피하고 `현재 상태 + 변경 이벤트 + 시간·일별 집계` 구조로 운영한다.

### 10.1 권장 테이블

#### managed_devices

- 장비 등록 정보
- 지점·위치·컴퓨터 이름
- Tailscale IP
- Agent 포트
- 운영체제
- 사용 여부
- 표시 순서

#### printers

- 복합기 모델
- 제조사
- 일련번호
- 프린터 IP
- 연결 방식
- SNMP 지원 여부
- EWS 지원 여부
- 연결 PC

#### device_current_status

- 장비별 최신 상태 한 건
- PC 온라인 상태
- Agent 상태
- 프린터 상태
- 마지막 응답 시각
- 현재 오류
- 대기열 수

#### printer_supplies

- 토너·드럼·퓨저·폐토너통 최신 상태
- 잔량 퍼센트
- 예상 남은 페이지
- 임계치 상태

#### printer_trays

- 용지함별 현재 상태
- 용지 크기
- 용지 종류
- 잔량 상태

#### status_events

- 상태 변경 이벤트
- 장애 발생
- 장애 해제
- 토너 단계 진입
- 용지 부족
- 오프라인·온라인 전환

## 20. 대표자 설명용 핵심 문장

I-PRINT는 30개 지점에 흩어진 복합기와 전용 PC를 하나의 웹 화면에서 실시간으로 확인하고 관리하는 통합 관제 시스템이다.

프린터가 오프라인이 되거나 토너·용지가 부족하고 용지가 걸리면 관리자가 전화받기 전에 텔레그램으로 먼저 알림을 받을 수 있다.

각 복합기에서 발생하는 출력량, 소모품, 장애, 복구 시간을 DB에 축적하여 향후 토너 교체 시점과 장비 교체 우선순위를 예측할 수 있다.

일반 사용자는 복합기에 붙은 QR코드를 스캔해 사용법, 현재 상태, 이용 요금, 담당자 전화, 카카오톡 상담, 길찾기를 모바일에서 바로 확인할 수 있다.

따라서 I-PRINT는 단순한 프린터 관리 페이지가 아니라 복합기 운영, 원격 유지보수, 사용자 안내, 장애 접수, 데이터 분석을 통합한 플랫폼이다.

## 22. 결론

약 30개 지점에 기업용 HP 복합기와 전용 PC가 각각 설치되어 있고 기존 SSH 또는 원격 관리자 접근이 가능하다면, I-PRINT는 현장 방문을 최소화하면서 전체 장비를 중앙에서 운영할 수 있는 매우 적합한 환경을 갖추고 있다.

Tailscale은 안전한 사설 통신망을 제공하고, OpenSSH는 관리자 명령 실행 통로를 제공하며, I-PRINT Agent는 프린터와 PC 상태를 자동 수집한다.

중앙 서버는 실시간 상태, 변경 이벤트, 일별 출력량, 소모품 상태, 장애와 복구 이력을 DB에 축적한다.

텔레그램 알림을 통해 장애를 선제적으로 대응하고, QR 모바일 페이지를 통해 일반 사용자의 문의와 불편을 줄일 수 있다.

단기적으로는 1개 지점 시범 운영과 실제 HP 복합기 모델별 데이터 수집 검증이 우선이다.

중기적으로는 30개 지점 전체 관제와 텔레그램 알림을 완성한다.

장기적으로는 축적된 데이터를 기반으로 소모품 예측, 장애 예측, 장비 교체 추천, 지점별 운영 분석까지 제공하는 복합기 운영 데이터 플랫폼으로 발전시킬 수 있다.
