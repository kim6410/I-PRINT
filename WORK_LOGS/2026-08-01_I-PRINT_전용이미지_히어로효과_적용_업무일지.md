대시보드는 다른 프로젝트의 경로나 서비스에 의존하지 않고 `/home/bourne/I-print/assets` 내부 파일만 사용합니다.

### 3. 히어로 이미지 전환 효과 적용

상단 히어로 영역에 다음 효과를 적용했습니다.

- 이미지 2개 레이어 교차 사용
- 30초 단위 이미지 변경
- 3.2초 페이드 전환
- 천천히 확대·이동하는 Ken Burns 효과
- 다음 이미지 미리 불러오기
- 무작위 이미지 선택
- 사용자가 움직임 최소화 설정을 사용하면 애니메이션 완화

### 4. 글자 가독성 유지

이미지 위에서도 제목과 상태 문구가 잘 보이도록 다음 효과를 적용했습니다.

- 왼쪽 청색 계열 그라데이션
- 하단 어두운 그라데이션
- 제목과 설명에 텍스트 음영
- 실시간 상태 표시의 대비 강화

### 5. 기존 기능 보호

다음 기능은 변경하지 않았습니다.

- 리스트 보기 기본값
- 카드 보기 전환
- 사용자 보기 설정 저장
- 검색
- 5초 실데이터 갱신
- 프린터 상태 표시
- 대기열 초기화 UI
- SQLite 인쇄 작업 이력
- 모바일 화면
