## DB 마이그레이션

기존 `printer_jobs.db`와 데이터를 유지한 채 아래 필드를 추가했다.

### alert_time_groups

- `start_date TEXT NOT NULL DEFAULT ''`
- `end_date TEXT NOT NULL DEFAULT ''`

기존 `days_json`, `start_time`, `end_time`과 결합해 다음 조건을 표현한다.

- 적용 시작일
- 적용 종료일
- 월요일~일요일 선택
- 시작 시간
- 종료 시간
- 자정을 넘는 시간대 지원

### alert_history

- `policy_id INTEGER`

테스트 또는 실제 알림이 어떤 정책에 의해 발생했는지 연결한다.

## 화면 연결

시간대 설정 카드마다 아래 입력을 DB와 연결했다.

- 시작 날짜
- 종료 날짜
- 시작 시간
- 종료 시간
- 월·화·수·목·금·토·일 체크
- 날짜·요일·시간 저장 버튼

날짜 범위를 비우면 기간 제한 없이 동작한다.

## 실제 감시 엔진 연결

프린터 대기열 알림은 `queue_delay` 장애 유형에 연결된 활성 정책의 날짜·요일·시간대가 현재 시각과 일치할 때만 전송한다.

PC·에이전트·Tailscale 장애도 해당 장애 유형에 연결된 활성 정책의 일정이 일치할 때만 전송한다.

야간 시간처럼 시작 시간이 종료 시간보다 늦은 경우 자정을 넘는 시간대로 판정한다.
