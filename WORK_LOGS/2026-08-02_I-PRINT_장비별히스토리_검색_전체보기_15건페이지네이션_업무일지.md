# I-PRINT 장비별 히스토리 화면 업무일지

- 작업일: 2026-08-02
- 대상: `/home/bourne/I-print`

## 요청 내용

- 관제 카드의 장비명을 누르면 해당 장비의 히스토리 화면으로 이동
- 선택한 장비 자동 필터
- 검색 기능
- 전체 장비 보기
- 페이지당 15건 페이지네이션

## 구현 내용

### 1. 장비명 링크

- 카드 보기와 리스트 보기의 장비명을 링크로 변경했습니다.
- `/history?device_id={장비ID}` 형식으로 이동합니다.
- 선택한 장비가 히스토리 화면에서 자동 필터됩니다.

### 2. 장비 상태 누적 DB

`device_status_history` 테이블을 추가했습니다.

저장 항목:

- 장비 ID와 이름
- 수집 시각
- PC/Tailscale 상태
- CPU, 온도, 메모리, 디스크
- 프린터와 스풀러 상태
- 출력, 대기, 오류 수
- 에이전트 응답 여부와 오류 상세

실제 연결 장비의 상태만 저장합니다.
상태가 바뀌면 즉시 저장하고, 변화가 없으면 마지막 저장 후 5분이 지난 경우에만 저장합니다.

### 3. 히스토리 화면

- 새 파일: `device_history.html`
- 주소: `/history`
- 로그인 보호 적용
- 해당 장비 자동 필터
- 장비 선택 드롭다운
- 상태·프린터·오류 내용 검색
- `전체 장비 보기` 버튼
- 페이지당 15건
- 이전/다음 및 페이지 번호 이동

### 4. API

- `GET /api/device-history`
- 파라미터: `page`, `search`, `device_id`
- 장비 목록, 결과 건수, 전체 페이지, 현재 페이지와 이력을 반환합니다.
