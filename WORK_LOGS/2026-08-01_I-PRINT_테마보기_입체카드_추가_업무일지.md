# I-PRINT 테마 보기 입체 카드 추가 업무일지

작업일: 2026-08-01

## 작업 목적

기존 리스트 보기와 카드 보기를 유지하면서, 컴퓨터 카드가 더 강한 음영과 입체감을 갖는 별도 테마 보기를 추가했습니다.

## 변경 내용

- 상단 보기 전환에 `테마 보기` 버튼 추가
- 보기 방식 3종 구성
  - 리스트 보기
  - 카드 보기
  - 테마 보기
- 사용자 선택값은 기존 `iprintViewMode` LocalStorage에 저장
- 테마 보기는 기존 카드 데이터와 기능을 그대로 재사용
- 테마 카드에 강한 외부 그림자와 내부 하이라이트 적용
- 마우스를 올리면 카드가 약간 상승하도록 처리
- 상태별 테두리와 은은한 광원 적용
  - 온라인: 청록색
  - 출력 중: 파란색
  - 대기: 노란색
  - 오류: 빨간색
- 카드 내부 상태·계기판·프린터 영역에도 약한 음영 추가
- 리스트 보기와 일반 카드 보기의 기존 디자인은 변경하지 않음

## 유지된 기능

- 5초 실시간 상태 갱신
- 검색
- 대기열 초기화
- 한글 상태 표시
- 리스트 보기 기본값
- 사용자 보기 방식 저장
- 히어로 이미지 전환 효과
