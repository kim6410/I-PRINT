## 5. 대시보드 UI 개선

메인 제목을 `I-PRINT 숭실대학교`로 변경했습니다.

`5800X와 Mac mini만 실데이터, 나머지는 테스트 슬롯`

카드 화면은 한 줄에 3개가 표시되도록 구성했으며, 한 화면에서 많은 장비를 확인할 수 있도록 카드 높이와 내부 여백을 줄였습니다.

- TEMP
- MEM
- DISK
- 프린터명

- Printer Status
- Last Action
- Printing
- Queued
- Error
- Total

CPU·온도·메모리·디스크 수치는 화면에서 정수로 반올림해 표시합니다.

실제 원본 수집값은 소수점 상태로 유지합니다.

Reset Print Queue의 긴 문구는 작은 SVG 새로고침 아이콘으로 변경해 카드 폭을 줄였습니다.

## 6. 리스트 보기와 카드 보기 전환

프린터 관리 업무에 맞춰 기본 화면을 `리스트 보기`로 변경했습니다.

상단에 다음 보기 전환 버튼을 추가했습니다.

- 리스트 보기
- 카드 보기

사용자가 선택한 보기 방식은 브라우저 `localStorage`의 `iprintViewMode` 값으로 저장됩니다.

따라서 새로고침하거나 브라우저를 다시 열어도 마지막으로 선택한 보기 형태가 유지됩니다.

### 리스트 보기

- 기본값
- 한 줄에 2개
- 프린터 중심의 2줄형 컴팩트 카드
- 건물명 또는 컴퓨터명
- 프린터명
- PC Online·Offline
- Tailscale 또는 Agent 상태
- Spooler 상태
- Printer 상태
- Printing·Queued·Error
- 마지막 갱신 상태
- 대기열 초기화 아이콘

### 카드 보기

- 기존 PC 상세 카드 유지
- 한 줄에 3개
- CPU·온도·메모리·디스크 등 유지보수 정보 확인용

검색어를 입력한 상태에서 보기를 전환해도 검색 조건이 유지됩니다.

5초 실시간 갱신이 실행되어도 사용자가 선택한 보기 방식은 변경되지 않습니다.

## 7. 리스트 상태 인지성 개선

복잡한 기능을 추가하지 않고 프린터 상태를 빠르게 읽을 수 있는 최소 UI만 적용했습니다.

리스트 카드 왼쪽 상태 바:

- 정상·Online: 초록색
- Printing: 파란색
- Queued: 노란색
- Error: 빨간색
- 미연결 테스트 슬롯: 회색

Printing 상태인 프린터에는 프린터명 앞에 작은 파란 점이 은은하게 움직이도록 적용했습니다.

강한 점멸이나 화면 전체 애니메이션은 사용하지 않았습니다.

Online 장비에는 연결 상태를 쉽게 확인할 수 있도록 초록 상태점이 표시됩니다.

이번 단계에서 제외한 기능:

- 자동 상태 정렬
- 우측 상세 Drawer
- 강한 깜빡임
- 복잡한 애니메이션
- 화면 밀도를 떨어뜨리는 추가 버튼
