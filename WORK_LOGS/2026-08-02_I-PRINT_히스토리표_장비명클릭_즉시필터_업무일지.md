## 요청 내용

장비가 많을 때 검색창이나 장비 선택 목록에서 하나씩 찾지 않고, 히스토리 표에 표시된 장비명을 누르면 해당 장비 기록만 즉시 조회되도록 변경합니다.

## 변경 내용

- 히스토리 표의 장비명을 클릭 가능한 버튼으로 변경했습니다.
- 장비명을 클릭하면 해당 행의 `device_id`를 장비 필터로 적용합니다.
- 현재 검색어는 그대로 유지합니다.
- 현재 페이지는 1페이지로 이동합니다.
- 장비 선택 드롭다운, 제목, 필터 배지, 표 결과, CPU·온도 그래프가 클릭한 장비 기준으로 함께 갱신됩니다.
- 기존 전체 장비 보기, 검색, 페이지당 15건 페이지네이션은 유지했습니다.
