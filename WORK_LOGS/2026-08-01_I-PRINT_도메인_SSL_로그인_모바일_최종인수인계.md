## 5. PC·모바일 자동 분기

접속 환경에 따라 화면을 자동으로 분리하도록 구현했습니다.

- `/`: PC 브라우저는 PC 대시보드, 모바일 브라우저는 모바일 화면으로 자동 분기
- `/mobile`: 모바일 전용 화면 직접 접속
- `?view=pc`: 모바일에서도 PC 화면 강제 표시

PC 화면과 모바일 화면은 같은 관제 데이터를 사용하지만 화면 구조와 조작 방식을 각각 최적화했습니다.

모바일 User-Agent를 사용한 외부 HTTPS 요청에서도 로그인 화면으로 정상 분기되는 것을 확인했습니다.

## 9. 504 Gateway Timeout 원인과 해결

도메인과 SSL 연결 직후 외부에서 504 Gateway Timeout이 발생했습니다.

원인은 Nginx Proxy Manager Docker 네트워크에서 호스트의 `8897/tcp` 포트로 접근할 때 방화벽이 연결을 차단한 것이었습니다.

Nginx Proxy Manager가 사용하는 Docker 대역에 아래 허용 규칙을 추가했습니다.

```text
172.19.0.0/16 → 8897/tcp 허용
```

규칙 적용 후 Nginx Proxy Manager에서 I-PRINT 서비스로 연결이 정상화됐고 외부 HTTPS 접속도 복구됐습니다.
