# I-PRINT 가짜 장비 테스트 알림 텔레그램 미발송 수정

## 작업 일시
2026-08-02

## 문제
설정 화면의 테스트 버튼이 `TEST-PC / TEST-PRINTER`라는 가짜 장비를 실제 장애처럼 텔레그램으로 발송했습니다.

## 수정 내용
- 설정 화면 버튼 이름을 `텔레그램 테스트 알림`에서 `DB·화면 테스트`로 변경했습니다.
- 테스트 실행 시 실제 텔레그램 발송 함수를 호출하지 않도록 변경했습니다.
- 테스트 결과는 `alert_history`에만 저장합니다.
- 저장 상태는 `테스트 완료`, 발송 횟수는 0회로 기록합니다.
- 테스트 이력은 즉시 확인 및 복구 완료 상태로 저장해 미확인 장애 수에 포함되지 않게 했습니다.
- 기존 TEST-PC/TEST-PRINTER 테스트 이력도 테스트 완료 상태로 정리했습니다.

## 실제 자동 감시 유지
- 5800X와 Mac mini 실제 상태 감시는 그대로 유지합니다.
- 실제 출력 대기열 지연 감시는 그대로 유지합니다.
- 샘플 문서와 가짜 테스트 장비는 텔레그램 실발송 대상이 아닙니다.

## 검증
- Python 문법검사 PASS
- settings.html 파싱 PASS
- SQLite integrity_check=ok
- 서비스 active
- /health 정상
- 테스트 API 반환: telegram_sent=false, preview_only=true
- 신규 테스트 이력: status=테스트 완료, send_count=0
