# 2026-08-01 I-PRINT 관리자 로그인 접근제어 업무일지

## 작업 목적

I-PRINT 대시보드를 외부에 공개하기 전 관리자만 화면과 API에 접근할 수 있도록 간단한 로그인 화면과 서버 세션 인증을 추가했습니다.

## 적용 계정

- 관리자 아이디: `i-print`
- 관리자 비밀번호: `ssu`

현재 값은 초기 운영용 기본값입니다.
서버 환경변수 `IPRINT_ADMIN_USERNAME`, `IPRINT_ADMIN_PASSWORD`로 변경할 수 있도록 구성했습니다.

## 수정 파일

- `/home/bourne/I-print/app.py`
- `/home/bourne/I-print/login.html`

기존 `index.html`과 `mobile.html`은 수정하지 않았습니다.

## 구현 내용

### 로그인 화면

- `/login`에 중앙 모달형 관리자 로그인 화면 추가
- 아이디와 비밀번호 입력
- 로그인 실패 문구 표시
- 로그인 성공 시 기본 주소 `/`로 이동

### 서버 인증

- 인증 쿠키 이름: `iprint_admin_session`
- HttpOnly 쿠키 사용
- SameSite Lax 적용
- 세션 유지시간 12시간
- HMAC 기반 서명 토큰 사용

### 보호 대상

로그인하지 않은 상태에서는 다음 경로에 접근할 수 없습니다.

- `/`
- `/mobile`
- `/api/printer-jobs`
- `/api/devices/5800x/status`
- `/api/devices/macmini/status`
- 대기열 초기화 등 기타 API

화면 경로는 `/login`으로 302 이동하고 API는 HTTP 401 JSON을 반환합니다.

### 공개 유지 경로

- `/login`
- `/api/login`
- `/health`
- `/assets/*`

### 로그아웃

- `/logout` 접속 시 인증 쿠키 삭제 후 로그인 화면으로 이동

### 모바일 자동 분기 유지

로그인 후에도 기존 모바일 분기 기능을 그대로 유지합니다.

- PC에서 `/` 접속: PC 화면
- 휴대전화에서 `/` 접속: `/mobile`로 302 이동
- 휴대전화에서 `/?view=pc`: PC 화면
- PC에서 `/mobile`: 모바일 화면 직접 확인

## 검증 결과

- Python 문법 검사: PASS
- 로그인 HTML UTF-8 구조: PASS
- 비로그인 `/`: 302 `/login`
- 비로그인 `/mobile`: 302 `/login`
- 비로그인 API: 401
- 잘못된 계정 로그인: 401
- 정상 계정 로그인: 200 및 HttpOnly 쿠키 발급
- 로그인 후 PC `/`: 200
- 로그인 후 모바일 `/`: 302 `/mobile`
- 로그인 후 모바일 `/?view=pc`: 200
- 로그인 후 `/mobile`: 200
- 로그인 후 작업 이력 API: PASS
- 서비스 상태: active

## 외부 공개 전 남은 보안 작업

현재 비밀번호 `ssu`는 짧으므로 실제 인터넷 공개 직전에는 긴 비밀번호로 교체해야 합니다.

Hostinger HTTPS 배포 시 다음 환경변수를 별도로 지정하는 것을 권장합니다.

- `IPRINT_ADMIN_USERNAME`
- `IPRINT_ADMIN_PASSWORD`
- `IPRINT_AUTH_SECRET`

HTTPS 운영 시 인증 쿠키의 Secure 속성도 활성화해야 합니다.
