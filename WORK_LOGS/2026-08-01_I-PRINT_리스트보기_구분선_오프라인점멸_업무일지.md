# I-PRINT 리스트 보기 구분선·오프라인 점멸 업무일지

작업일: 2026-08-01

## 작업 목적

리스트 카드의 높이와 정보 구조는 유지하면서 시각적 구분감을 높이고, 오프라인 장비를 빠르게 찾을 수 있도록 개선했습니다.

## 변경 내용

- 리스트 카드 좌측 컬러 상태선을 제거했습니다.
- 컴퓨터 정보와 프린터 정보 사이에 은은한 세로 구분선을 추가했습니다.
- 출력·대기·오류·최근 상태 영역 위에 약한 가로 구분선을 추가했습니다.
- 오프라인 카드에 `state-offline` 상태 클래스를 명시적으로 부여했습니다.
- 오프라인 상태 점과 문구만 1.55초 주기로 천천히 점멸하도록 적용했습니다.
- 화면 전체 또는 카드 전체가 깜빡이지 않도록 제한했습니다.
- 운영체제의 움직임 최소화 설정에서는 점멸 애니메이션을 사용하지 않습니다.

## 유지한 기능

- 리스트 보기와 카드 보기 전환
- 사용자 보기 설정 저장
- 검색
- 5초 상태 갱신
- 대기열 초기화
- 상태별 카드 음영

## 검증 항목

- 좌측 컬러라인 제거
- 내부 세로·가로 구분선 적용
- 오프라인 상태 클래스 적용
- 오프라인 상태만 점멸
- 대시보드 HTTP 응답
- Git 작업 트리 및 미추적 파일
