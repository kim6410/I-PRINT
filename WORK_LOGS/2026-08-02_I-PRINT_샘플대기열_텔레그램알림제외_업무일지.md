# 2026-08-02 I-PRINT 샘플 대기열 텔레그램 알림 제외 업무일지

## 작업 목적

프린터 관제 테스트용으로 입력된 `sample_document_*.pdf` 대기열이 실제 장애로 판정되어 1분마다 텔레그램 알림을 보내는 문제를 해결한다.

## 수정 파일

- `/home/bourne/I-print/app.py`

## 수정 내용

텔레그램 대기열 감시 SQL에 아래 제외 조건을 추가했다.

```sql
AND LOWER(COALESCE(document_name, '')) NOT LIKE 'sample_document_%'
```

화면과 DB의 샘플 데이터는 삭제하지 않았다.

실제 문서 대기열 가운데 `Queued`, `Queue`, `Waiting` 상태이면서 3분 이상 대기한 작업만 기존과 동일하게 알림 대상이 된다.
