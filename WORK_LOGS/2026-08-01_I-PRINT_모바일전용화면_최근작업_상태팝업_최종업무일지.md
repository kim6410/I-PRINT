## 10. 아직 하지 않은 작업

### 10-1. 기본 주소 모바일 자동 분기

현재 모바일 화면은 아래 주소에서 정상 동작한다.

- `http://192.168.0.32:8897/mobile`

그러나 휴대전화에서 기본 주소 `/`로 접속할 때 자동으로 `/mobile`로 보내는 기능은 아직 구현하지 않았다.

다음 작업 목표:

- 휴대전화에서 `/` 접속 시 `/mobile`로 302 이동
- PC에서 `/` 접속 시 기존 PC 화면 유지
- 휴대전화에서 `/?view=pc` 접속 시 PC 화면 강제 표시
- `/mobile` 직접 접속은 그대로 유지

이 기능은 `mobile.html`만으로 구현하면 안 된다.

서버의 `/` 라우트에서 User-Agent를 확인해야 하므로 `app.py` 한 파일 수정이 필요하다.

권장 모바일 판정 키워드:

- android
- iphone
- ipad
- ipod
- mobile

작업 전 반드시 기존 `/` 라우트를 확인하고 중복 라우트를 만들지 않는다.

검증 항목:

1. PC User-Agent + `/` → HTTP 200, PC 화면
2. Android User-Agent + `/` → HTTP 302, `/mobile`
3. iPhone User-Agent + `/` → HTTP 302, `/mobile`
4. 모바일 User-Agent + `/?view=pc` → HTTP 200, PC 화면
5. `/mobile` → HTTP 200
6. `/health` → HTTP 200
7. 서비스 재시작 후 동일 결과 재확인
