# I-PRINT 리스트 보기 입체감 강화 업무일지

작업일: 2026-08-01

## 작업 목적

리스트 보기의 각 컴퓨터·프린터 카드가 배경과 분리되어 보이도록 입체감을 강화했다.

## 변경 내용

- 리스트 카드 배경을 단색에서 어두운 그라데이션으로 변경
- 카드 외부 그림자와 하단 음영 강화
- 카드 상단 내부 하이라이트 추가
- 마우스 오버 시 2px 상승 효과 적용
- 온라인 상태 카드에 청록색 테두리와 은은한 광원 적용
- 출력 중 상태 카드에 파란색 테두리와 광원 적용
- 대기 상태 카드에 노란색 테두리와 광원 적용
- 오류 상태 카드에 빨간색 테두리와 광원 적용
- 기존 왼쪽 상태 표시선에 상태별 발광 효과 추가

## 유지한 기능

- 리스트 보기 2열 구조
- 카드 보기 입체 테마
- 검색
- 보기 방식 저장
- 5초 실시간 데이터 갱신
- 개별 대기열 초기화
- SQLite 인쇄 작업 이력
