## 구현 내용

### 메인 관제 화면

- 기존 `장비 관리` 버튼 아래에 `설정` 버튼 추가
- 설정 버튼은 `/settings`로 이동
- 모바일 폭에서는 두 버튼 위치가 겹치지 않도록 별도 위치 보정

### 알림 및 관제 설정 페이지

- 상단에 `관제 화면으로` 복귀 버튼 추가
- 알림 정책
- 담당자 관리
- 위치 / PC 그룹
- 장애 유형 설정
- 시간대 설정
- 알림 이력
- 정책별 ON/OFF 스위치
- 담당자별 수신 ON/OFF 스위치
- 샘플 정책과 담당자·위치·이력 카드 표시
- 실제 저장 전임을 안내하는 토스트와 안내 문구 포함

## 안전 범위

- 텔레그램 발송 로직 수정 없음
