# I-PRINT 숭실대학교

숭실대학교 내 원격 컴퓨터와 프린터 상태를 한 화면에서 확인하기 위한 관제 대시보드입니다.

## 현재 구성

- FastAPI 기반 웹 대시보드
- SQLite 기반 최근 프린터 작업 게시판
- 검색 및 페이지당 10건 페이지네이션
- Tailscale 전용 원격 통신
- 5800X 실시간 CPU, 온도, 메모리, 디스크, 프린터 상태 수집
- Mac mini 실시간 CPU, 메모리, 디스크, 프린터 상태 수집
- 학생회관 01~06 테스트 슬롯
- 숭실대학교 건물별 프린터 위치 테스트 슬롯 19개

## 접속

- 내부망: http://192.168.0.32:8897
- Samba: \\192.168.0.32\I-print

## 실제 연결 장비

- 5800X: Tailscale 100.117.206.9
- Mac mini: Tailscale 100.116.128.62
- Dell Server: Tailscale 100.109.184.64

## 데이터 갱신

- 컴퓨터 및 프린터 상태: 5초
- 최근 프린터 작업 게시판: 5초

## 운영 원칙

- 실제 에이전트가 연결된 장비만 실데이터로 표시합니다.
- 에이전트가 설치되지 않은 카드는 Offline 테스트 슬롯으로 표시합니다.
- SQLite 운영 DB, 캐시, 로컬 백업 파일은 Git 저장소에 포함하지 않습니다.
